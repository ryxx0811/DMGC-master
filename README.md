# Deep Multi-Graph Clustering (DMGC)

Master's project on uncovering molecular and cellular interactions in disease using deep multi-graph learning.

This repository contains the source code, reproducible analysis notebooks, and selected project results. Input datasets, matrices, model checkpoints, and notebook cell outputs are excluded from version control.
